# Ocean-vehicle-C4 (AUV Sim Haisai)

> C4 Intelligent Navigation Competition - Autonomous Underwater Vehicle Simulation Project.

## 📖 About
This repository contains my source code and simulation records for the C4 (Intelligent Navigation and Control) track of the National Ocean Vehicle Design Competition. As an Automation sophomore, I'm starting from zero to build a basic AUV control and obstacle avoidance simulation.

## 🛠️ Tech Stack
- Engine: Unity (2021.3.45f2c1)
- Language: C#
- Tools: Git, VS Code

## 📂 Current Progress
- [x] Unity environment setup & basic scene creation
- [x] `.gitignore` configured to keep the repo clean
- [ ] Basic PID depth/direction control
- [ ] A* path planning
- [ ] Static/Dynamic obstacle avoidance

## 🚀 How to Run
1. Clone this repository.
2. Open with Unity Hub (version 2021.3.45f2c1 or later).
3. Open the `SampleScene` and hit Play.
